# Seven Voices Author Sources

This directory preserves author-supplied primary doctrine sources for the Seven Voices project.

## Governance

- The Albanian originals are preserved verbatim.
- These files are source material, not executable engine contracts.
- Source claims are not automatically scientific, linguistic, historical, lexical, reviewed, or production facts.
- Literary and metaphorical statements are not deterministic engine rules by default.
- Future translations must be separate artifacts and must never replace the originals.
- Technical extraction must remain separate and cite stable source IDs and Git-addressable passages.
- An `ENGINE_AUTHORIZED_RULE` requires separate reviewed technical-contract authorization.

Each chapter file carries only minimal source metadata: `sourceId`, `chapter`, `language`, `sourceKind`, `sourceStatus`, and `engineAuthority`.
