# Milestones Index

This folder is the entrypoint for implementation milestones, delivery checkpoints, and historical engineering progress in the ZË-RO repository.

## Purpose

Milestone docs record what was planned, what was delivered, and what was proven at a given stage.

They are not the same thing as:
- governing contract law
- active subsystem specs
- validation artifacts
- research notes

This lane exists to answer questions like:

- what milestone introduced a capability
- what was considered DONE at that stage
- which milestone doc records the proof or delivery checkpoint
- what implementation history led to the current repo state

For governing rules, read:
- `docs/constitution/README.md`
- `docs/ENGINE_CONTRACT_FREEZE.md`
- `docs/RECOVERY.md`

## What lives here

This folder should contain:
- milestone specs
- DONE milestone records
- delivery checkpoints
- implementation-history references
- milestone-linked proof docs

## How to read this folder

Use milestone docs for:
- engineering history
- delivery sequencing
- DONE criteria at the time
- locating older implementation decisions

Do not treat milestone docs as automatically equivalent to current governing rules.

If a milestone doc conflicts with:
- `docs/ZERO_REALITY_GUIDE.md`
- `docs/ENGINE_CONTRACT_FREEZE.md`
- `docs/ROADMAP_V1_BOUNDARY.md`
- `docs/RECOVERY.md`

then the governing docs win.

## Relation to other lanes

- `docs/specs/` = active reference/spec material
- `docs/process/` = workflow and operational discipline
- `docs/validation/` = drift/baseline proof artifacts
- `docs/research/` = research-facing notes and papers
- `docs/milestones/` = implementation history and delivery checkpoints

## Current rule

Use this lane to preserve engineering history without letting old milestone prose pretend to be current contract law.
