## Purpose

Contract docs describe stable expectations that other parts of the repo may rely on.

This folder is for contract-facing records that are worth preserving as explicit reference artifacts, especially when they capture an achieved or locked state.

For governing rules, read:
- `docs/constitution/README.md`
- `docs/ENGINE_CONTRACT_FREEZE.md`
- `docs/RECOVERY.md`

## What lives here

This folder should contain:
- achieved contract records
- locked done-state contract references
- contract-facing proof documents that are worth preserving outside milestone prose

## Reading order

If you are investigating a contract question in this lane:

1. active governing or semantic contract doc
2. this folder’s achieved contract record
3. milestone/history docs only if more context is needed

## Rule

Do not treat a contract record as the same thing as:
- a semantic contract definition
- a milestone note
- a validation artifact

Those are related, but not identical.
