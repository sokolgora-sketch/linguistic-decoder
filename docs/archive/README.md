# Archive Index

This folder is the entrypoint for historical or superseded docs kept for reference in the ZË-RO repository.

## Purpose

Archive docs preserve older material without letting it masquerade as current truth.

These docs may still be useful for:
- historical context
- tracing earlier ideas
- understanding past framing or structure
- recovering old references

But they are not current governing law, not active specs, and not front-door guidance.

For governing rules, read:
- `docs/constitution/README.md`
- `docs/ENGINE_CONTRACT_FREEZE.md`
- `docs/RECOVERY.md`

## What belongs here

This folder should contain:
- superseded drafts
- historical blueprints
- older structures no longer treated as canonical
- reference material preserved for traceability

## Current archived docs

- `blueprint.generator-placeholder.md`
- `ZE-RO_v1-blueprint.historical.md`

## Rule

If an archive doc conflicts with:
- current governing docs
- current lane indexes
- current contract or validation artifacts

then the current docs win.

## Reading order

Only read archive docs after:
1. `README.md`
2. `docs/README.md`
3. governing docs
4. the relevant active lane index

Use archive docs for history, not authority.
