## 4. Why Cohort 02 is not publication-ready

Cohort 02 should not be public yet because:

1. Portuguese `/â/` improved under V1-V5, but only after redesign.
2. Portuguese `/â/` needs a second V1-V5 replication before being promoted.
3. Romanian `/ă/` remains unresolved after v0.1 and v0.2.
4. Turkish `/ı/` remains a high-region pressure-audit case.
5. Norwegian `/ø/` and Danish `/ø/` are supportive but modest because controls did not collapse.
6. French `/ø~œ/` is strong, but one strong case is not enough for a clean Cohort 02 public package.
7. The current archive is internal, not a public methods package.
8. A public version needs paper-safe language, a clean limitations section, and a final checksum table.
9. The public story must not imply that every case supports the framework.

The correct internal takeaway is:

> Cohort 02 improves classification discipline by separating support cases from pressure cases.

That is not the same as a public proof claim.
