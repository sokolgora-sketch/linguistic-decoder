# Embryo-First Functional Discovery — One-Embryo Proof v1 — M2

## Fresh Target Selection and Manual Proof Preregistration v0.1

Status: `FROZEN_PREREGISTRATION_CONTRACT_ONLY`

Contract ID: `OPEN_INSTRUMENT_ONE_EMBRYO_PROOF_V1_M2_PREREGISTRATION_V0_1`

The machine-readable `preregistration.json` is the normative frozen M2
contract. This package freezes procedure and integrity rules only. It does
not select a real target or embryo, create a real blind payload, perform
source research, freeze a real function, reveal a target, or authorize
production/runtime evidence.

## Operational one-embryo definition

One embryo is one target-bound structural-hypothesis case. Exactly one
eligible opaque target case and one structurally defensible embryo are bound
before blind source research. The existing deterministic structural discovery
order is preserved. There is no semantic ranking, expected-function ranking,
manual preference, or replacement attempt after a Null or mismatch.

The future case is complete only when the same frozen embryo, blind payload,
pre-reveal function-or-Null, and independently authorized revealed target
sense are evaluated together. A single case does not establish a universal
word-structure claim, a historical origin claim, production authority, or a
canonical consonant meaning map.

## Fresh target and sense boundary

The future pool is defined by rules only in this lane. It must exclude the
57-case baseline, prior targets, prior reveals, controls, and previously
researched words. Candidate identity is normalized deterministically for
comparison, but source spelling and locators remain in the sealed selection
record. Ambiguous identities or unresolved/conflicting senses are excluded or
return an explicit Null according to the sealed record.

Selection is deterministic over stable opaque candidate identifiers, with
code-unit lexical ordering as the tie-break. The rule never uses semantic
attractiveness, translation, etymology, source hits, expected correspondence,
or manual preference. No real pool is embedded here and no real selection was
made.

The target-sense authority is separate from blind discovery. A future proof
must bind one independently reviewable sense identifier before blind research;
the blind operator receives no target word, sense, gloss, translation, or
target locator. Polysemy remains explicit; a sense is not selected after an
embryo or source result is seen.

## Structural embryo and blind payload

The embryo reuses `structuralHypothesisDiscovery.v0_1` and preserves its
hypothesis ID, embryo, voice path, reduction steps, expansion chain, reason
codes, evidence references, and claim boundaries. A structural Null is valid
when no defensible result exists. The frozen payload contains only the opaque
case identity, structural embryo/fingerprint, voice path, predeclared source
universe/search/stop identifiers, and claim boundaries.

The payload is canonical UTF-8 JSON with recursively sorted object keys,
preserved array order, and a final LF. Its exact bytes and SHA-256 are stored
before discovery. Target word, pronunciation, sense/gloss, translation,
etymology, historical target material, functional evidence, expected
function, and post-reveal interpretation are forbidden payload fields.

## Search and pre-reveal freeze

The future source universe is sealed before search and may contain only
traceable reviewed linguistic dictionaries, historical dictionaries/corpora,
dialectal or vernacular sources, reconstructed-form sources, and primary
linguistic sources. Queries may use only the frozen embryo or an authorized
identity-preserving transform. New source traditions, target lookup,
translation/semantic/etymological search, unlogged mutation, and post-hoc
function search are forbidden.

The pre-reveal result is the existing strict-blind function-candidate set or
an explicit Null. It preserves Fact / Inference / Hypothesis / Unknown,
`no_single_winner`, and `user_decides`. The result is materialized, serialized,
hash-pinned, and immutable before reveal. Null does not authorize a second
embryo or search.

## Durable artifact and reveal invariant

The required pre-reveal artifacts are:

1. `M2_PREREGISTRATION_CONTRACT`
2. `M2_TARGET_POOL_DEFINITION`
3. `M2_TARGET_SELECTION_RECORD`
4. `M2_STRUCTURAL_EMBRYO_FREEZE`
5. `M2_BLIND_PAYLOAD`
6. `M3_PRE_REVEAL_DISCOVERY`
7. `M3_PRE_REVEAL_FUNCTION_OR_NULL`
8. `M3_PRE_REVEAL_HASH_MANIFEST`

Each artifact must exist as exact bytes, carry a SHA-256 and byte length,
be created before reveal, and be immutable after freeze. The selection record
may contain target semantics only in a sealed controller-side artifact; it is
never passed to the blind operator. The manifest itself is hash-pinned.

`NO REQUIRED PRE-REVEAL ARTIFACT -> NO ADVANCE TO REVEAL.` Missing bytes,
unverifiable fingerprints, mismatches, post-freeze mutation, incomplete
search state, unfrozen pre-reveal result, blindness violation, or missing
manual authorization all fail closed. Bytes are never reconstructed from
terminal output, chat, process memory, or post-reveal material.

`M5_POST_REVEAL_CORRESPONDENCE_RESULT` is not required to authorize reveal,
but it is required—alongside every pre-reveal artifact—for a valid completed
proof. This directly prevents the M6 archival gap from being treated as a
complete proof.

## Correspondence and claims

After an authorized reveal, the sealed pre-reveal object is compared with the
independently authorized target sense. Scientific outcomes reuse the existing
strict-blind vocabulary: `FUNCTIONAL_CORRESPONDENCE`, `LEXICAL_EQUIVALENCE`,
`FORM_RESEMBLANCE_ONLY`, `HISTORICAL_RELATION_ONLY`,
`INSUFFICIENT_CORRESPONDENCE`, or `NULL`. Procedural validity is separate:
missing or unverifiable artifacts produce `INVALID_PROOF`, not a scientific
Null.

No outcome retroactively changes the embryo, source universe, payload,
selection rule, or pre-reveal function. One successful case does not prove
universal non-arbitrariness, universal consonant semantics, historical origin,
all-language or all-word validity, production truth, cognacy, borrowing,
language superiority, or a single etymological winner. One Null does not prove
the opposites.
