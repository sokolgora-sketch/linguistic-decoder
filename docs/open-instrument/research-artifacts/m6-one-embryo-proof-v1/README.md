# One-Embryo Proof v1 archival package

This is a non-production durability archive for the completed
`open-instrument-m2-one-embryo-proof-v1` experiment.

The original M2, M3, and M5 canonical byte payloads were not recovered. The
reported original hashes are therefore preserved as historical report values,
not as independently verified hashes. The archival JSON is a newly created
representation and has its own hash in `hash-manifest.json`.

The result remains `INSUFFICIENT_CORRESPONDENCE`. This package does not create
runtime evidence, catalog rows, source authority, or production authorization.

Verify with:

```text
node scripts/openInstrumentM6DurabilityArtifactVerification.v1.mjs
```
