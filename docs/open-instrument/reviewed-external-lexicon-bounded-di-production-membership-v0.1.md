# Reviewed External Lexicon Bounded DI Production Membership v0.1

Status: IMPLEMENTED_CONTRACT.

Project lane: Open Instrument / ZËRO.

## Purpose

This contract admits the reviewed Albanian DI source row to production only
for bounded functional lexical projection.

The bounded statement is:

- Albanian `di` is an attested standalone lexical form associated with
  knowing;
- this lexical function may motivate a candidate reading involving knowledge,
  study, or learning;
- the user decides.

This is not a historical-origin claim.

## Admission path

DI production projection requires both:

1. explicit source-ID membership in
   `PRODUCTION_SOURCE_ROW_IDS_V0_1`;
2. successful machine-readable functional runtime authorization.

The existing authorization requires:

- functional lexical readiness;
- reviewed-accepted source status;
- no historical-origin claim;
- no historical-transmission claim;
- no winner claim;
- no language-superiority claim;
- no candidate-truth claim;
- no publication-evidence claim;
- no scientific-evidence claim;
- `user_decides`.

## Source posture

The current reviewed citation is the stable Wiktionary Albanian `di` entry.

It records:

- attested form: `di`;
- lexical meaning: know / knowledge;
- locator: `Albanian > Etymology 1 > Verb > di: to know`;
- URL: `https://en.wiktionary.org/wiki/di#Albanian`.

The row also records a DPEWA/FGJSH reference trail.

A direct DPEWA/FGJSH locator or archived authoritative dictionary snapshot
remains unresolved for historical-authority or stronger-source claims.

That unresolved stronger-authority question is not a prerequisite for the
bounded lexical statement represented by this production lane.

## Source-packaging checklist boundary

The existing `direct_authoritative_locator_or_archive` checklist passes for
the bounded lexical source package because the reviewed row has:

- a stable source URL;

- a stable source hash or archive reference.

This checklist result confirms source packaging for the lexical statement.

It does not establish that a direct DPEWA or FGJSH entry was inspected.

Direct DPEWA/FGJSH authority remains unresolved for historical-authority or
stronger-source claims.

The checklist implementation is unchanged and is not used as historical-origin
proof.

## Runtime behavior

When `DI` is emitted as a live RootMap key, such as for `study`, reviewed
functional evidence may be appended through the generic reviewed projection
path.

The evidence must include:

- the reviewed lexical form;
- the reviewed lexical meaning;
- the Wiktionary locator and URL;
- `historicalOriginClaim=not_claimed`;
- `winnerClaim=not_claimed`;
- `languageSuperiorityClaim=not_claimed`;
- `userDecisionPosture=user_decides`.

The evidence must not include:

- the DA DOI;
- a fabricated direct DPEWA locator;
- historical derivation;
- borrowing direction;
- earliest-origin language;
- language ownership;
- candidate truth;
- publication proof;
- scientific proof.
