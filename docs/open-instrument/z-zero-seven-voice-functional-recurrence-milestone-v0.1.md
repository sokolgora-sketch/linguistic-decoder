# ZË-RO Seven-Voice Functional Recurrence milestone v0.1

Date: 2026-08-29

Milestone ID:

`SEVEN_VOICE_FUNCTIONAL_RECURRENCE_V0_1`

## Purpose

This milestone establishes a core ZË-RO research principle in explicit code and contract form so it is not dependent on conversational memory.

ZË-RO treats the seven canonical voices:

`A, E, I, O, U, Y, Ë`

as the primary functional comparison layer.

Consonants may shape lexical structure, framing, articulation, and expansion.

Consonants do not independently drive the Seven-Voices path.

The governing ZË-RO research hypothesis is:

> Concept-equivalent forms across languages may preserve or recur around one or more of the same canonical Seven Voices even when their consonantal frames, complete surface forms, and complete voice paths differ.

This is called:

**Seven-Voice Functional Recurrence.**

## Functional nucleus

For a declared concept cohort, every form preserves its own complete Seven-Voice path.

The recurrence layer then asks which canonical voices occur in every declared comparison path.

Those shared voices form the v0.1:

**shared functional nucleus**

The nucleus is therefore not required to equal:

- the whole word
- the whole vowel path
- a historical root
- a standalone lexical form
- a phonetic identity
- a cognate set

It is a deterministic recurrence observation across the declared comparison forms.

## Vowels carry the functional comparison

The central ZË-RO posture is:

**The Seven Voices carry the functional comparison. Consonants are structural frames and carriers.**

This milestone does not claim that consonants are linguistically meaningless.

It means consonants do not independently create a Seven-Voice functional recurrence.

For recurrence analysis, the canonical voice path is the governing comparison layer.

## Genericity

The implementation must be concept-independent.

Forbidden logic includes:

~~~ts
if (word === "water") {
  return ["U"];
}
~~~

The recurrence algorithm instead:

1. receives a concept id
2. receives declared comparison forms
3. extracts each comparison form through the existing Seven-Voice authority
4. retains each full voice path
5. computes the canonical set intersection
6. orders the shared voices using the canonical symbolic order
7. emits the shared functional nucleus
8. preserves explicit claim boundaries

The algorithm must work for arbitrary future concepts.

## Truth hierarchy

The following distinctions are mandatory.

### Fact within declared comparison forms

- each declared comparison form
- its deterministic Seven-Voice path
- the canonical voice intersection
- the resulting shared functional nucleus

### Research hypothesis

- that the recurrent canonical voice carries or motivates the shared concept/function
- for example, that U expresses a WATER-related functional principle

### Not claimed

This milestone does not claim:

- phonetic identity
- historical origin
- historical transmission
- cognacy
- borrowing
- a single historical winner
- candidate truth
- universality

The user-decision posture remains:

`user_decides`

## Recurrence is not universality

A shared voice in a selected cohort does not imply that every language must encode the concept with that voice.

Counterexamples are valid evidence.

Future research should test:

- larger language cohorts
- independent language families
- source-attested lexical forms
- orthographic versus transliteration recurrence
- phonetic recurrence as a separately declared mode
- expected baseline frequencies
- whether observed recurrence exceeds appropriate baselines

Failure to reproduce a recurrence is a valid result.

Null remains valid.

## No etymological winner

Seven-Voice Functional Recurrence is not an origin-ranking system.

A shared canonical voice does not establish:

- which language is older
- which language borrowed from another
- historical descent
- lexical ownership
- proto-language priority

The existing ZË-RO:

`no_single_winner`

posture remains intact.
