## Purpose

This contract adds a machine-readable authorization decision for bounded
functional lexical runtime projection.

## Authorization requirements

A source row may pass this contract only when:

- its source ID is explicitly allowlisted for bounded functional projection;
- functional lexical readiness passes;
- the source row remains reviewed and accepted;
- historical origin remains unclaimed;
- historical transmission remains unclaimed;
- no winner is claimed;
- no language superiority is claimed;
- candidate truth remains unclaimed;
- publication evidence remains unclaimed;
- scientific evidence remains unclaimed;
- the result remains user-decidable.

The previous production path depends partly on prose markers embedded in
source notes and citation review notes.

Bounded functional authorization must be a deterministic contract rather
than an inference from mutable prose.

Future runtime work must consume this authorization object explicitly.
