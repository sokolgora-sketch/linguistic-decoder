# Security Policy

## Our Philosophy
ZË-RO is built on the principle of Deterministic Truth. This extends to our security. We prefer private disclosure over public exploits to ensure the integrity of the linguistic engine.

## Supported Versions
We currently only provide security updates for the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |

## Reporting a Vulnerability
If you find a security flaw or a "logic leak" in the 7-Voice engine, do not open a public Issue. 

Please use GitHub's **Private Vulnerability Reporting** feature to contact the maintainer directly. 

We aim to acknowledge all legitimate reports within 48 hours and provide a deterministic fix as soon as possible.
